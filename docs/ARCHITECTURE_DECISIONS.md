# Architectural decisions requiring primary review

These are intentionally decisions, not hidden defaults:

- **Target identity:** three exact local `Cohere2MoeForCausalLM` verifier families remain separate: AutoGPTQ integer group-32, Cohere QAD-trained NVFP4 W4A16 group-16 with FP8 scales, and Cohere FP8. All share 49 layers, 2048 hidden size, and 128 experts / top-8 routing, but checkpoint and runtime distribution identity do not transfer.
- **Draft shape:** no North draft geometry is selected. `docs/NORTH_DRAFT_CANDIDATES.md` compares the acceptance-first 8-full-layer/5-feature shape and long-context 6-layer (5-SWA + 1-full)/8-feature shape. Both are dense-draft investigations; copying North's MoE is not justified.
- **Layer selection:** the five-feature spread `[1, 12, 24, 35, 46]` maps to entries `[2, 13, 25, 36, 47]`; the eight-feature spread `[1, 7, 14, 20, 27, 33, 40, 46]` maps to `[2, 8, 15, 21, 28, 34, 41, 47]`. Exact AutoGPTQ, W4A16, and FP8 runtime traces prove both mappings and 2048-wide states. Shared token IDs do not imply shared feature values. Neither draft geometry is selected.
- **Mask token and tied vocabulary weights:** North's `tokenizer.json` contains special `<MASK_TOKEN>` at ID `1`, consistent in the added-token table and vocabulary. All three exact checkpoints contain the same BF16 `[262144, 2048]` `model.embed_tokens.weight` and no separate LM-head tensor. Masked draft slots use frozen row 1 from that exact tensor; output logits use the same parameter as a tied projection. No learned fallback mask or synthetic LM head is permitted unless introduced as a separately reviewed experiment.
- **Features:** the estimator shows that a dataset-wide raw cache is costly (for 800K × 3072, 5 × 2048 BF16 features: about 45.8 TiB), while a 512-token ring is about 10 MiB for one five-feature stream or 16 MiB for eight features. The implemented in-memory consumer validates exact runtime/token/layer identity, clones request-owned features, preserves request boundaries, rejects overflow, and acknowledges the FIFO head only after a successful optimizer step. A separate orchestration module fingerprints immutable handoffs and deletes only the matching unchanged feature/lock files after that acknowledgement; `feature_stream.py` never deletes them. This ordering passed a live FP8 release gate. Pilot orchestration must disable vLLM prefix caching and add a durable crash/restart commit ledger. AutoGPTQ TP=2, FP8, and the pinned PR #48032 W4A16/MARLIN runtime are byte-repeatable under their validated configurations. The former stock-Marlin tolerance envelope is diagnostic evidence only.
- **Precision:** BF16 can initialize a draft if approved, but it cannot replace AutoGPTQ, Cohere W4A16, or Cohere FP8 as the exact branch teacher or claimed deployment target.
- **Layout integration:** the dependency-free slice validates concatenated sampled-block ordering, bidirectional within-block visibility, inter-block isolation, and frozen target-context visibility through each clean anchor. The isolated optional `.[torch]` adapter materializes `[1, Q]` query tensors and a dense `[Q, C + Q]` boolean oracle (frozen context first, query keys second), then exposes the same rule as a FlexAttention block-mask predicate when available. This establishes CPU construction parity only; it does not inject target features, run an attention kernel, or validate GPU behavior.
- **Teacher interface:** retained identity manifests independently pin AutoGPTQ, Cohere W4A16, and Cohere FP8 config/index/shards. Bounded vLLM connector traces prove exact five-feature extraction for all three, including TP replication for the TP=2 AutoGPTQ deployment. Bitey's W4A16 and FP8 paths are pinned to deterministic PR #48032 CUDA MARLIN and TRITON respectively; Rocky backends would be separate final-adaptation distributions. The online ring consumer passes one exact transaction per verifier family; pilot orchestration must still release transient connector files and must not accumulate them into a corpus. Generic Cohere2Moe auxiliary-state plumbing remains isolated in vLLM branch `experiment/north-dflash` at `a1cad4f67` and pinned composite runtime images.
- **Training-step boundary:** optional PyTorch code accepts only detached selected clean teacher states with an ordered layer-ID tuple and contiguous clean positions, concatenates `[B, C, H]` states to `[B, C, L*H]`, and supplies direct frozen vocabulary references to a draft adapter. Its CE is an unshifted weighted mean over exactly the masked future labels because each packed masked query predicts its own position. The local-reference adapter uses full RoPE positions `0..C-1` plus packed query positions and converts the audited bool mask to additive `[B, 1, Q, C + Q]`. CPU fixtures and one exact GPU transaction per verifier family prove draft-only optimization and frozen shared weights. Retained pilots are intentionally narrower than the generic forward contract: checkpoints require North's tied output, an allowlisted adapter, exact response/request/release ledgers, and ordered AdamW state. This does not validate cache, FlexAttention, production North attention, or optimization quality.
