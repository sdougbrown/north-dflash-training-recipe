# Architectural decisions requiring primary review

These are intentionally decisions, not hidden defaults:

- **Target identity:** exact local North `Cohere2MoeForCausalLM`, 49 layers, 2048 hidden size, 4-bit int AutoGPTQ with group size 32 and 128 experts / top-8 routing.
- **Draft shape:** five layers and block size 16 are paper-shaped candidates only. A dense draft is proposed as an investigation baseline; copying North's MoE is not justified yet.
- **Layer selection:** `[1, 12, 24, 35, 46]` is mechanically derived as zero-based transformer-block indices using the reference dflash spread formula for 49 target layers and five draft layers. The reference Qwen extractor reads `hidden_states[layer_id + 1]`; whether Cohere2Moe has that embedding-output offset is unverified.
- **Mask token:** tokenizer-audited contract: North's `tokenizer.json` contains special `<MASK_TOKEN>` at ID `1`, consistent in both the added-token table and model vocabulary, and within target `vocab_size: 262144`. No arbitrary CLI fallback is permitted.
- **Features:** the estimator shows that a dataset-wide raw cache is costly (for 800K × 3072, 5 × 2048 BF16 features: about 45.8 TiB), while a 512-token ring is about 10 MiB for one stream. The actual online/ring design must preserve the feature alignment needed by sampled anchors.
- **Precision:** BF16 can initialize a draft if approved, but it cannot replace the exact int4 AutoGPTQ expert-only teacher or become the claimed deployment target.
- **Layout integration:** the dependency-free slice validates concatenated sampled-block ordering, bidirectional within-block visibility, inter-block isolation, and frozen target-context visibility through each clean anchor. The isolated optional `.[torch]` adapter materializes `[1, Q]` query tensors and a dense `[Q, C + Q]` boolean oracle (frozen context first, query keys second), then exposes the same rule as a FlexAttention block-mask predicate when available. This establishes CPU construction parity only; it does not inject target features, run an attention kernel, or validate GPU behavior.
- **Teacher interface:** the feature manifest fingerprints `config.json` and records complete int4 AutoGPTQ fields and selected block IDs. The exact installed config, HF index, and seven shards have now been hashed and independently reverified in `configs/north-int4-teacher-checkpoint-identity.json`. Hidden-state extraction remains unimplemented. Generic Cohere2Moe auxiliary-state plumbing is isolated in vLLM branch `experiment/north-dflash` at `a1cad4f67`, pending a real runtime gate.
- **Training-step boundary:** optional PyTorch code accepts only detached selected clean teacher states with an ordered layer-ID tuple and contiguous clean positions, concatenates `[B, C, H]` states to `[B, C, L*H]`, and supplies direct frozen embedding/LM-head module references to a draft adapter. Its CE is an unshifted weighted mean over exactly the masked future labels because each packed masked query predicts its own position. The synthetic adapter verifies this interface on CPU only; it is not a North/Qwen architecture. A capability-gated `dflash.DFlashDraftModel` skeleton deliberately refuses forward execution pending target/KV alignment and attention-mask review.
